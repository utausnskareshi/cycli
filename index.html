Cycli とは？

Cycli（サイクリ）は、生理周期を管理するためのプログレッシブ・ウェブ・アプリ（PWA）です。 スマートフォンのホーム画面に追加すれば、ふつうのアプリと同じように、 オフラインでも 使えます。

記録したデータは、暗号化されてあなたの端末にだけ保存されます。 サーバーには一切送信されません。

できること

  • ●
    予測・カレンダー

    次回の生理予定日、排卵日、PMS警戒期、ダイエット効率期を自動表示。

  • ●
    記録・セルフケア

    経血量・痛み・基礎体温・体重・症状・気分をワンタップで記録。

  • ●
    モード切替

    月経管理／妊活／妊娠中／ジュニア など、目的に合わせて画面を切り替え。

  • ●
    ピル服薬管理

    毎日の服薬チェック・飲み忘れ防止アラーム。

  • ●
    医療機関向けレポート

    記録データを産婦人科の先生に提示できる、見やすい形に整えて表示。

📱 iPhone（iOS）でのインストール手順

  1. Safari でこのページを開きます。 ※Chrome や他ブラウザだとインストールできません
  2. 下部メニューの 共有ボタン（□↑）をタップ。
  3. メニューから 「ホーム画面に追加」 を選びます。
  4. 「追加」をタップ → ホーム画面に「Cycli」アイコンが出ます。
  5. ホーム画面のアイコンをタップして起動してください。

🤖 Android でのインストール手順

  1. Chrome でこのページを開きます。
  2. 画面下に 「Cycliをホームに追加」 の案内が出たらタップ。
  3. 出ない場合は、右上の ⋮ メニュー → 「アプリをインストール」 または「ホーム画面に追加」を選びます。
  4. 確認画面で「インストール」をタップ。
  5. ホーム画面のアイコンから起動してください。

⚠️ ご利用前にお読みください

  • 本アプリは医療機器ではありません。診断や治療の判断に使わないでください。
  • データはこの端末のブラウザ内（IndexedDB）に暗号化して保存されます。
  • ブラウザのデータを消去したり、端末を変更すると記録が失われます。 設定からエクスポート（バックアップ）してください。
  • iOS では、ホーム画面に追加した後にのみ通知が機能します。
